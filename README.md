# The Dojo

## Just cloned this?

**If you are already talking to Claude:** quit it first — Ctrl+C twice. It only
notices new skills when it starts up, so a session that began before you cloned
this cannot see the dojo yet.

Then, at your terminal:

```
cd ~/dojo
claude --dangerously-skip-permissions
```

and type:

```
/dojo
```

That is everything. Sensei explains the rest as you need it.

---

## What this is

A school for getting comfortable with the terminal, Claude Code, skills and MCP.
It does not teach commands. It teaches concepts, and how to ask.

The first belts are on the web at **https://lakotafox.com/dojo**, which takes you
from a fresh Mac to a working Claude Code install. Everything after that is here.
