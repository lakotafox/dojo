# The Dojo

## Just cloned this?

**Say this to the Claude you are already talking to:**

> Read ~/dojo/.claude/skills/dojo/SKILL.md and be my sensei.

That is it. No restarting, no new terminal.

<sub>Later, to pick up where you left off: start Claude in this folder and type
`/dojo`. That is the same thing, just shorter — the slash command is a shortcut
to that file, and it becomes available once a session starts inside this
folder.</sub>

---

## What this is

A school for getting comfortable with the terminal, Claude Code, skills and MCP.
It does not teach commands. It teaches concepts, and how to ask.

The first belts are on the web at **https://lakotafox.com/dojo**, which takes you
from a fresh Mac to a working Claude Code install. Everything after that is here.

## What is in here

| | |
|---|---|
| `index.html` | the dashboard — sensei will tell you when to open it |
| `training-log.json` | your progress. Claude writes it, the dashboard reads it |
| `CLAUDE.md` | notes for Claude about this project |
| `.claude/skills/dojo/` | sensei, as a skill |
| `mcp/dojo-server.js` | the Black Belt capstone |
| `gen_sensei.py` | sensei himself, every pixel placed by hand |
